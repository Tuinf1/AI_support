# ИИ агент для анализа обращений в поддержку

Командный проект по кейсу Intelligence Cup «Газпром нефти». Цель — предложить и проверить прототип агента, который находит повторяющиеся обращения и передаёт продуктовым командам проверяемые сигналы.

## Материалы

- `md/Решение_ИИ_агент.md` — основной текст решения и схемы.
- `word/Решение_ИИ_агент.docx` — версия для чтения и сдачи.
- `word/Пункт_5_Эффект.md` — отдельный пункт 5 в требуемом формате.
- `word/Пункт_5_Эффект.docx` — версия пункта 5 для чтения.
- `md/Сценарий_презентации.md` и `word/Сценарий_презентации.docx` — план выступления.
- `md/AI_Footnotes.md` и `word/AI_Footnotes.docx` — необязательное приложение.
- `Кейс_Искусственный интеллект .pdf` — исходное задание.
- `заметки.txt` — рабочие вводные, которые требуют проверки.

Основной текст должен укладываться в 15 000 знаков. Для официальной подачи принимаются DOCX, DOC или PDF; пункт 5 оформляется отдельно как Markdown. Ссылки на дополнительные материалы не должны подменять содержание основного решения.

## Прототип

План и границы первой версии описаны в [`prototype/README.md`](prototype/README.md). Прототип должен работать на обезличенных тестовых обращениях и воспроизводить цепочку: подготовка → классификация → поиск кандидатов на повтор → группировка → проект сигнала → ручное подтверждение. Интеграция с реальной тикет-системой и внутренними моделями потребует доступов и согласования схемы данных.

## Совместная работа

Репозиторий предполагается **приватным**. Для изменений используем отдельные ветки и pull request; перед публикацией проверяем, что в коммит не попали персональные данные, записи звонков, секреты и выгрузки тикетов. Рабочие входные данные и результаты прототипа исключены через `.gitignore`.
